## Как запустить

Нужны Node.js 24 и Yarn 4 через Corepack. На винде удобнее через Git bash.

- `native`: открыть `native/index.html` в браузере.
- `infra`: `cd infra && corepack enable && yarn install && yarn serve`
- `framework`: `cd framework && corepack enable && yarn install && yarn dev`

## Что было сложным

- **Инфраструктура.** Yarn 4, Corepack, режим установки зависимостей, Vite, ESLint в плоском конфиге, Prettier и строгий TypeScript. В основном делал по образцу с семинаров, но под конец на фреймворк этапе стало ещё сложней.
- **TypeScript.** Пришлось разбираться с `null` у DOM-элементов, `unknown` из `localStorage`, индексными сигнатурами и строгими флагами вроде `noUncheckedIndexedAccess`
- **Тесты.** jsdom не умеет `matchMedia` и `AnimationEvent`, `user-event` зависает с фейковыми таймерами, а CSS Modules хеширует классы. Каждую из этих штук прихрдмлось понимать, осознавать и пытаться чинить отдельно
- **React.** Эээээээттттооооо интересно! но доооолгооо и многа всего и мало что пока осталось в голове. Компоненты, хуки, Zustand и разделение логики и разметки дались тяжко
- **Доступность и адаптив.** Нужно было не сломать то, что уже сделано в native, и сохранить нормальные подписи, фокус, `aria`-атрибуты и поведение на маленьких экранах.
